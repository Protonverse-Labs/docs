This page states what has and has not been verified so nobody has to guess. It reflects the project owner's own status record.

## Current stage

**Working hardware prototype.**

## Verified

- Physical Proton AI Core Vision+ boards have been produced
- The hardware has been tested physically
- It is ESP32-S3-based
- USB-C works
- Wi-Fi works
- The current firmware is operational
- The OV5640 camera is operational, including capture and streaming
- The firmware can be flashed successfully

## Not yet verified, not yet claimed

These have intentionally **not** been measured, or are not claimed until they are:

- On-device AI acceleration
- Specific frame-rate (FPS) figures at any resolution
- Current consumption figures
- Operating temperature range
- Industrial certification
- CE and FCC certification

If any of these appears as a fact elsewhere, please [open an issue](https://github.com/Protonverse-Labs/proton-ai-core-vision-plus/issues). It should not be stated without measured data behind it.

## Production

- **Mass production:** not yet launched
- **Crowd Supply:** the [pre-launch page](https://www.crowdsupply.com/protonverse-labs/proton-ai-core-vision-plus) is live

## Documentation

The documentation is under active development alongside the hardware and firmware. If something looks wrong, incomplete or unverifiable, please report it through the [GitHub repository](https://github.com/Protonverse-Labs/proton-ai-core-vision-plus).
